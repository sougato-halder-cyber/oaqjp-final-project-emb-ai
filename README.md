# Emotion Detector

## Project Name
AI-Based Emotion Detection Web Application

## Description
This project is a web-based emotion detection application that uses IBM Watson NLP library to analyze text and detect emotions including anger, disgust, fear, joy, and sadness. The application is built with Flask and deployed as a web service.

## Features
- Real-time emotion detection from text input
- Web interface using Flask
- Error handling for blank inputs
- Unit tested for reliability
- Static code analysis compliant

## Technologies Used
- Python
- Flask
- IBM Watson NLP
- Requests library
- UnitTest
- Pylint
